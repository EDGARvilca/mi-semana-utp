# Sincronizador de Mi Semana UTP

1. Abre `chrome://extensions`.
2. Activa **Modo desarrollador**.
3. Pulsa **Cargar descomprimida** y selecciona esta carpeta `extension`.
4. Mantén iniciada la sesión en `https://class.utp.edu.pe/student/courses`.
5. En Mi Semana UTP pulsa **Sincronizar UTP+class**.

La extensión solo lee las actividades visibles de UTP+class y las envía localmente a la pestaña del organizador. No lee ni guarda contraseñas.
